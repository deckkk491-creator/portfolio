# Антикварная лавка «Ларец»

Демо: https://deckkk491-creator.github.io/portfolio/портфолио/сайты/антикварная-лавка/

Концепт-сайт для портфолио: лавка, эксперты и лоты вымышлены, форма заявки ничего не отправляет.

- Стиль музейной инвентарной карточки: двойные линейки, номера лотов, гравюрные иллюстрации в SVG.
- Карманные часы на первом экране показывают текущее время.
- Интерактивный конвертер золотниковой пробы в метрическую.
- Форма оценки по фото с превью снимков и проверкой полей.
- Светлая и тёмная тема, адаптивная вёрстка, мобильное меню.

Стек: HTML, CSS, JavaScript, SVG.
