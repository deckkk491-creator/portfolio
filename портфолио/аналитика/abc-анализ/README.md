# ABC-анализ ассортимента из выгрузки

Демо: https://deckkk491-creator.github.io/portfolio/портфолио/аналитика/abc-анализ/

**Что делает:** превращает CSV-выгрузку из 1С, «МойСклад» или кабинета маркетплейса в готовый ABC-анализ.

- Читает CSV с разделителем «;» или «,», числа с пробелами и запятой, кодировки UTF-8 и Windows-1251.
- Сам находит колонки с названием товара и выручкой; их можно выбрать вручную.
- Группы: A — первые 80% выручки, B — следующие 15%, C — остальные 5%.
- Кривая Парето, таблица с рекомендациями и выгрузка результата в CSV.

Файл обрабатывается в браузере и никуда не отправляется. Стек: HTML, CSS, JavaScript.
