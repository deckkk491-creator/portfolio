# Цветочная мастерская «Мирт»

Демо: https://deckkk491-creator.github.io/portfolio/sites/flower-shop/

Концепт-сайт для портфолио: магазин, флористы, цены и контакты вымышлены, заказы никуда не отправляются.
Структура — как у крупных московских сервисов доставки цветов (каталог с поводами, доставка за 2 часа, фото букета до отправки, подписка), оформление — своё.

## Страницы

| Страница | Что внутри |
|---|---|
| `index.html` | Главный экран с покачивающимся букетом, поводы, хиты, блоки «для молодёжи» и «для особых дат», шаги, подписка, отзывы |
| `catalog.html` | 16 букетов, фильтры по поводу, цвету и цене, сортировка; фильтры сохраняются в адресе страницы |
| `product.html?id=…` | Букет с выбором размера S/M/L (иллюстрация меняет пышность), ваза, открытка, похожие букеты |
| `cart.html` | Корзина: количество, зоны доставки, бесплатная доставка от 7 000 ₽, промокод `МИРТ10`, форма заказа с проверкой полей |
| `subscription.html` | Тарифы; календарь сезона, где можно отметить любимые цветы, вычеркнуть ненужные, пропустить месяц, указать аллергию, гамму и цветы, которые никогда не привозить; пожелания попадают в форму. Оплата за каждую доставку — после фото букета |
| `delivery.html` | Зоны и цены, калькулятор доставки, оплата, гарантия свежести, частые вопросы |
| `about.html` | История, цифры, ценности, команда |
| `contacts.html` | Адрес, схема проезда, форма вопроса флористу |

## Детали

- Все букеты — SVG-иллюстрации, которые собираются кодом из описания состава (`assets/bouquet.js`): пионы, розы, ранункулюсы, тюльпаны, анемоны, ромашки, эвкалипт, лаванда, гипсофила; упаковка — бумага, шляпная коробка или ваза.
- Анимации: появление блоков при прокрутке, плавный переход между страницами, покачивание букета, лепестки на главном экране, бегущая строка. При включённой настройке «уменьшить движение» анимации отключаются.
- Палитра: тёплая розоватая бумага, пыльная малина и персиковый коралл; тёмная тема — тёплый вишнёво-шоколадный.
- Тема берётся из настроек устройства и меняется вместе с ними; ручной выбор действует до закрытия вкладки. Корзина хранится в браузере, маска телефона, адаптивная вёрстка от 360 px.

Стек: HTML, CSS, JavaScript, SVG — без фреймворков и сборки.
