# Кофейня «К», Тамбов

Демо: https://deckkk491-creator.github.io/portfolio/sites/coffee-k/

Неофициальный концепт-сайт для реальной кофейни «К» (Тамбов, Московская улица, 30а). Адрес, часы работы, удобства и короткие цитаты гостей взяты из открытой карточки [2ГИС](https://2gis.ru/tambov/firm/70000001083613209). Напитки, цены и фотографии — из [Telegram-канала кофейни](https://t.me/kkkkofe), владельцы разрешили их использовать.

## Страницы

| Страница | Что внутри |
|---|---|
| `index.html` | Главный экран с солнечными бликами, качающейся лампой и паром над чашкой, преимущества, популярные позиции, атмосфера, отзывы из 2ГИС, программа лояльности (бот @TenCups_bot: 6 напитков — 7-й в подарок, анимированная карта со штампами), блок «как найти» со схемой |
| `menu.html` | Меню по разделам с липкими вкладками, которые подсвечиваются при прокрутке. Нажатие на цену добавляет позицию в онлайн-заказ. Конструктор напитка: основа, размер, молоко, сироп, крепость — стакан перекрашивается, цена считается, напиток можно добавить в заказ |
| `about.html` | Кофейня в цифрах (в т.ч. минута от остановки и большая парковка), книжная полка, для кого это место, интерьер |
| `contacts.html` | Адрес, часы с подсветкой сегодняшнего дня, остановка и парковка, схема проезда, форма брони столика (демо) — время брони подстраивается под часы выбранного дня |

## Детали

- Онлайн-заказ навынос (демо): корзина на всех страницах, количество, «с собой» или «в зале», время готовности — «как можно скорее» или к нужному времени в часы работы, а после закрытия — предзаказ на утро. После оформления показывается номер заказа и статус «Принят → Готовим → Готов». Заказ никуда не отправляется.
- Контакты кофейни (телефон, WhatsApp, ВКонтакте) — из карточки 2ГИС, Telegram — от владельцев. Фото витрины, десертов и интерьера — из их канала: лента «Что сегодня в К» на главной, витрина в меню, книжная полка, интерьер и мини-маркет на странице «О кофейне».

- Часы работы: пн–пт 8:00–19:00, сб–вс 9:00–18:00 (в праздники график может меняться). Статус «Открыто до … / Закрыто · с …» считается по московскому времени с учётом дня недели.
- Стиль повторяет настроение зала: светлые стены, большие окна, плетёные абажуры, белые полки с книгами. Все иллюстрации — SVG в коде.
- Светлая и тёмная тема, адаптивная вёрстка, плавные переходы между страницами; при «уменьшить движение» анимации отключаются.

Стек: HTML, CSS, JavaScript, SVG.
