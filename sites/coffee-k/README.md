# Кофейня «К», Тамбов

Демо: https://deckkk491-creator.github.io/portfolio/sites/coffee-k/

Неофициальный концепт-сайт для реальной кофейни «К» (Тамбов, Московская улица, 30а). Адрес, часы работы, удобства и короткие цитаты гостей взяты из открытой карточки [2ГИС](https://2gis.ru/tambov/firm/70000001083613209). Меню на 2ГИС не опубликовано, поэтому состав и цены — ориентировочные; на сайте это отмечено.

## Страницы

| Страница | Что внутри |
|---|---|
| `index.html` | Главный экран с солнечными бликами, качающейся лампой и паром над чашкой, преимущества, популярные позиции, атмосфера, отзывы из 2ГИС, блок «как найти» со схемой |
| `menu.html` | Меню по разделам с липкими вкладками, которые подсвечиваются при прокрутке. Нажатие на цену добавляет позицию в онлайн-заказ. Конструктор напитка: основа, размер, молоко, сироп, крепость — стакан перекрашивается, цена считается, напиток можно добавить в заказ |
| `about.html` | Кофейня в цифрах, книжная полка, для кого это место, интерьер |
| `contacts.html` | Адрес, часы с подсветкой сегодняшнего дня, остановка, схема проезда, форма брони столика (демо) |

## Детали

- Онлайн-заказ навынос (демо): корзина на всех страницах, количество, «с собой» или «в зале», время готовности — «как можно скорее» или к нужному времени в часы работы, а после 19:00 — предзаказ на утро. После оформления показывается номер заказа и статус «Принят → Готовим → Готов». Заказ никуда не отправляется.
- Контакты кофейни (телефон, WhatsApp, ВКонтакте) — из карточки 2ГИС. Фотографии кофейни не используются без разрешения владельцев: на сайте стоит ссылка на их фото во ВКонтакте.

- Статус «Открыто до 19:00 / Закрыто» считается по московскому времени.
- Стиль повторяет настроение зала: светлые стены, большие окна, плетёные абажуры, белые полки с книгами. Все иллюстрации — SVG в коде.
- Светлая и тёмная тема, адаптивная вёрстка, плавные переходы между страницами; при «уменьшить движение» анимации отключаются.

Стек: HTML, CSS, JavaScript, SVG.
