# Дашборд продаж в Yandex DataLens

**Дашборд:** _ссылка появится после публикации_

**Для кого:** собственник, который раз в неделю открывает одну страницу и за минуту понимает, как идут продажи и где теряются деньги.

## Что на дашборде

| Блок | Чарт | Какой вопрос закрывает |
|---|---|---|
| KPI | Индикаторы: выручка, маржинальная прибыль, ДРР, заказы, средний чек | Сколько заработали за выбранный период |
| Динамика | Линейный: выручка по месяцам в разрезе каналов | Растём или нет, есть ли сезонность |
| Каналы | Столбчатый: выручка и маржинальная прибыль по каналам | Где больше денег после всех расходов |
| Реклама | Линейный: ДРР по месяцам и каналам | Окупается ли реклама |
| Категории | Таблица: выручка, доля возвратов, маржа по категориям | Какие категории тянут вниз |
| Покупатели | Столбчатый с накоплением: выручка новых и повторных | Возвращаются ли покупатели |
| Фильтры | Селекторы: период, канал, категория | Детализация под вопрос |

## Данные

Оба файла собирает скрипт [`prepare_data.py`](prepare_data.py) из базы [`data/marketplace.db`](../../data/):

- [`daily.csv`](daily.csv) — день × канал: заказы, выручка, себестоимость, комиссия, логистика, реклама, маржинальная прибыль. Для KPI, каналов и ДРР.
- [`sales.csv`](sales.csv) — позиции доставленных заказов: категория, город, SKU, тип покупателя, возврат. Для категорий и новых/повторных.

Почему две таблицы: реклама известна только по дням, и если склеить её с позициями заказов, сумма задвоится столько раз, сколько позиций было в этот день. Поэтому денежные итоги считаются на уровне «день × канал», а детализация — по позициям.

## Как собрать (≈30–40 минут)

1. Откройте [datalens.yandex.ru](https://datalens.yandex.ru) и войдите через Яндекс ID.
2. **Подключения → Создать → Файлы.** Загрузите `daily.csv` и `sales.csv`. Проверьте типы: `Дата` — дата, денежные поля — дробное число, `Возврат` — целое. Сохраните подключение как `Дом и уют — файлы`.
3. **Датасеты → Создать.** Сделайте два датасета: `Продажи по дням` (из `daily.csv`) и `Продажи по позициям` (из `sales.csv`).
4. В датасете `Продажи по дням` добавьте вычисляемые поля:
   ```
   ДРР, %              = SUM([Реклама]) / SUM([Выручка]) * 100
   Маржинальность, %   = SUM([Маржинальная прибыль]) / SUM([Выручка]) * 100
   Средний чек         = SUM([Выручка]) / SUM([Заказы])
   Месяц               = DATETRUNC([Дата], "month")
   ```
5. В датасете `Продажи по позициям` добавьте:
   ```
   Доля возвратов, %   = SUM([Возврат] * [Количество]) / SUM([Количество]) * 100
   Прибыль до рекламы  = SUM([Выручка] - [Себестоимость] - [Комиссия] - [Логистика])
   Месяц               = DATETRUNC([Дата], "month")
   ```
6. **Чарты** (Wizard):
   - *Индикатор* × 5: `SUM([Выручка])`, `SUM([Маржинальная прибыль])`, `[ДРР, %]`, `SUM([Заказы])`, `[Средний чек]`.
   - *Линейная диаграмма*: X — `Месяц`, Y — `SUM([Выручка])`, Цвета — `Канал`.
   - *Столбчатая диаграмма*: X — `Канал`, Y — `SUM([Выручка])` и `SUM([Маржинальная прибыль])`.
   - *Линейная диаграмма*: X — `Месяц`, Y — `[ДРР, %]`, Цвета — `Канал`.
   - *Таблица*: `Категория`, `SUM([Выручка])`, `[Доля возвратов, %]`, `[Прибыль до рекламы]`; включите цветовую заливку по доле возвратов.
   - *Столбчатая с накоплением*: X — `Месяц`, Y — `SUM([Выручка])`, Цвета — `Тип покупателя`.

   Закрепите цвета каналов во всех чартах одинаково: Wildberries — синий, Ozon — оранжевый, Сайт — зелёный.
7. **Дашборды → Создать.** Сверху селекторы (период по полю `Дата`, `Канал`, `Категория`), под ними индикаторы, затем графики. Свяжите селекторы с чартами обоих датасетов (ссылки по полям `Дата` и `Канал`).
8. Добавьте текстовый блок «Что видно из данных» с 3–4 выводами из [SQL-анализа](../sql-marketplace/).
9. **Доступ → Опубликовать** (публичная ссылка). Вставьте ссылку в начало этого README и в карточку проекта на главной странице портфолио.

## Проверка

После сборки сверьте KPI за весь период с SQL-проектом: выручка — 95,5 млн ₽, маржинальная прибыль — 17,8 млн ₽, ДРР — 16,8%. Если цифры расходятся, скорее всего, неверно задан тип поля или реклама попала в датасет по позициям.
