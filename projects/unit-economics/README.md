# Юнит-экономика товара на маркетплейсе

Демо: https://deckkk491-creator.github.io/portfolio/projects/unit-economics/

**Вопрос, на который отвечает:** сколько бизнес зарабатывает с одной продажи и какую долю рекламы товар выдерживает.

- Учитывает цену, себестоимость, комиссию маркетплейса, налог, хранение, логистику с учётом процента выкупа и ДРР.
- Показывает прибыль, маржинальность, ROI и предельный ДРР, при котором прибыль равна нулю.
- Разбивка цены по статьям расходов и таблица сценариев по доле рекламы.

Формула: прибыль = цена − себестоимость − цена × (комиссия + налог + ДРР) − логистика / выкуп − хранение.

Стек: HTML, CSS, JavaScript. Цифры по умолчанию — пример, не данные реального магазина.
