# Рынок вакансий аналитиков: что требуют и сколько платят

**Ноутбук:** [market.ipynb](market.ipynb) · **Данные:** настоящие, 1 648 вакансий с портала «Работа России» (открытый API, выгрузка 21.10.2026)

**Вопрос.** Я перехожу в аналитику и хотел понять по реальным данным, а не по рекламе курсов: каких аналитиков ищут, сколько им платят, какие навыки нужны и сколько вакансий открыто для начинающих.

## Что сделано
1. **Выгрузка через API** ([`fetch_vacancies.py`](fetch_vacancies.py)): поиск «аналитик» по всей стране, разметка навыков регулярными выражениями.
2. **Очистка:** полнотекстовый поиск вернул фармацевтов, программистов и химиков-аналитиков. После фильтра по названию должности осталось 587 вакансий, из них 528 за последние 12 месяцев.
3. **Классификация ролей** по ключевым словам в названии и навыкам: аналитик данных / BI, системный, бизнес-, финансовый, 1С, продаж и закупок.
4. **Зарплаты** по ролям, регионам и опыту: медианы с бутстреп-интервалами, потому что группы небольшие.
5. **Надбавка за навыки:** сравнение медиан, Манн — Уитни, бутстреп, повтор отдельно для Москвы и регионов, чтобы отделить эффект навыка от эффекта географии.

## Главное

| Что нашёл | Цифры |
|---|---|
| Больше половины вакансий «аналитика» — не IT | 55% вакансий: «аналитик» без уточнения, 1С, финансовый; медианы 41–57 тыс. ₽ против 93–117 тыс. у аналитиков данных, системных и бизнес-аналитиков |
| Для аналитика данных SQL — обязательный минимум | SQL в 74% вакансий, Python в 46%, статистика и A/B в 29%, BI в 17% |
| Москва платит в 2,5 раза больше регионов | медиана 142,5 тыс. ₽ против 57 тыс. ₽, p < 0,001 |
| Удалёнка — редкость на этом портале | явно указана в 3% вакансий |
| Половина вакансий доступна с опытом до года | медиана без опыта — 47,5 тыс. ₽, до года — 63 тыс., 1–3 года — 77 тыс., больше 3 лет — 125 тыс. |
| «Надбавка за SQL» — во многом эффект Москвы | по стране +48 тыс. ₽, внутри Москвы +10 тыс. ₽, и разница незначима |

## Ограничения
- На «Работе России» больше госсектора и регионального бизнеса, чем на hh.ru, поэтому абсолютные зарплаты ниже рыночных для IT. Корректнее сравнивать группы между собой.
- Навыки найдены по тексту вакансии: часть подразумевается, но не упоминается. Доли — нижняя оценка.
- Флаг BPMN при выгрузке совпадал со словом «требования», поэтому он исключён из анализа (в скрипте шаблон исправлен).
