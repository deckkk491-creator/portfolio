# Дашборд продаж по каналам

Демо: https://deckkk491-creator.github.io/portfolio/projects/sales-dashboard/

**Для кого:** руководитель, которому нужно за минуту понять, как идут продажи.

- KPI: выручка, заказы, средний чек, маржа — с изменением к прошлому году.
- Фильтры по каналу (Wildberries, Ozon, сайт) и кварталу.
- Выручка по месяцам в разрезе каналов, доли каналов, таблица категорий.
- Блок «Что видно из данных» с выводами, которые пересчитываются под фильтр.

Стек: HTML, CSS, JavaScript, SVG. Данные сгенерированы для демонстрации.
